Utility Management System — Spring Security
1. Описание проекта

Приложение предназначено для управления помещениями, приборами учёта коммунальных ресурсов, показаниями счётчиков и начислениями за потреблённые ресурсы.

В проекте реализованы:

регистрация пользователей;
аутентификация с использованием Spring Security;
разграничение доступа по ролям;
управление помещениями и счётчиками;
передача и подтверждение показаний;
формирование начислений;
оплата начислений;
защита API от CSRF-атак.

4. Аутентификация и авторизация

Для защиты API используется Spring Security.

Аутентификация выполняется с помощью HTTP Basic Authentication.

В системе предусмотрены две роли:

ADMIN

Администратор имеет следующие возможности:

создание помещений;
создание приборов учёта;
изменение и удаление помещений и счётчиков;
подтверждение показаний;
формирование начислений;
получение отчётов.
USER

Обычный пользователь имеет следующие возможности:

отправка показаний собственных счётчиков;
оплата собственных начислений;
просмотр доступных ему данных в соответствии с настройками безопасности.

Проверка принадлежности помещений, счётчиков и начислений выполняется на уровне бизнес-логики.

5. Защита CSRF

Для защиты от CSRF-атак используется CookieCsrfTokenRepository.

CSRF-защита применяется к запросам, изменяющим данные.

Для выполнения POST, PATCH и DELETE запросов необходимо передавать заголовок:

X-XSRF-TOKEN

Получение CSRF-токена выполняется через endpoint:

GET /api/auth/csrf

Для регистрации пользователя и получения CSRF-токена предусмотрены исключения из CSRF-проверки.
